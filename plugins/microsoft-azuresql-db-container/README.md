# Azure SQL Database container

From the Microsoft SQL product team. Local development against the Azure SQL Database container, the real cloud engine on your machine: running it, connecting to it, seeding and testing against it, importing an existing database, and proving the same code runs unchanged in Azure.

Every file under this directory is GENERATED by scripts/generate.mjs from catalog/plugins.json
and skills/. Edit the skill in skills/ and run `npm run generate`. A copy edited here fails the
parity gate.

Install it with `microsoft-azuresql-db-container@microsoft-sql`. See the repository README for the commands your
client uses.
